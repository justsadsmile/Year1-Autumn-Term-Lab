## How to Run

### C# Projects
```bash
# Open in Visual Studio or use .NET CLI
dotnet run --project BasicProgrammingLab1/BasicProgrammingLab1.csproj
```

### C Projects
```bash
# Compile with Visual Studio or GCC
gcc computer_science_lab1/main.c -o lab1.exe
```
